План: подготовить проект-заготовку UI-библиотеки, которую можно собрать и опубликовать в npm.

Что будет сделано:

1. Настроить npm-пакет
- Перевести `package.json` из приватного app-проекта в publishable library package.
- Добавить `private: false`, `version`, `description`, `main`, `module`, `types`, `exports`, `files`.
- Добавить скрипты:
  - `build:lib` для сборки библиотеки
  - `prepublishOnly` для автоматической сборки перед публикацией
- Использовать npm-настройки по аналогии с проектом [Elegant Grid](/projects/074530b7-0860-4ffd-8c27-35dbdb6c0a8f).

2. Добавить библиотечную точку входа
- Создать минимальный экспорт, например `src/lib/index.ts` или `src/components/library/index.ts`.
- Добавить заглушечный UI-компонент, например `UiLibraryPlaceholder`, чтобы пакет уже можно было импортировать из npm.
- Экспортировать типы компонента.

Пример будущего использования:

```tsx
import { UiLibraryPlaceholder } from "<package-name>";
import "<package-name>/styles.css";

export function App() {
  return <UiLibraryPlaceholder />;
}
```

3. Настроить library build
- Обновить `vite.config.ts`, чтобы в обычном режиме проект продолжал запускаться как preview/demo-приложение.
- Добавить отдельный режим `library`, который собирает npm-пакет в `dist`.
- Подключить генерацию `.d.ts` типов через `vite-plugin-dts`.
- Вынести React, React DOM и JSX runtime во внешние зависимости, чтобы они не попадали внутрь npm-бандла.

4. Добавить стили для npm-экспорта
- Подготовить минимальный CSS-файл библиотеки.
- Экспортировать его как `./styles.css`, чтобы пользователи могли подключать стили отдельно.
- Сохранить текущий app preview рабочим.

5. Добавить npm package hygiene
- Добавить `.npmignore` по образцу Elegant Grid, чтобы в npm попадали только нужные файлы.
- Обновить/создать `README.md` с краткой инструкцией установки, импорта и публикации.
- Оставить проект в состоянии “заглушка, готовая к npm”, без полноценного набора компонентов.

6. Заменить пустую стартовую страницу
- Убрать текущий blank placeholder на главной странице.
- Сделать простую landing/demo страницу библиотеки: название, описание, пример заглушечного компонента и короткая инструкция установки.

Технические детали:
- Проект останется на TanStack Start для preview/demo.
- Для npm-сборки будет использоваться Vite library mode.
- Потребуется добавить dev-зависимость `vite-plugin-dts`.
- Имя пакета в `package.json` нужно будет задать. Если не указано иное, я поставлю временное имя-заглушку вроде `@andreyfedkovich/ui-library-placeholder`, которое потом можно будет заменить перед публикацией.
