## Цель

Уменьшить размер шрифтов во всех компонентах библиотеки, не трогая `DialogSelect`. Корневая причина крупных шрифтов — миксины в `_text.scss` написаны в `rem` с расчётом на legacy-правило `html { font-size: 62.5% }` (1rem = 10px), которого в проекте нет, поэтому `1.4rem` сейчас рендерится как `22.4px` вместо задуманных `14px`.

## Решение

Добавить базовый font-size reset для библиотеки и убедиться, что DialogSelect (он в `px`) не пострадает.

### 1. `src/lib/styles.css` — добавить базовый reset

В начало файла добавить:

```css
html {
  font-size: 62.5%; /* 1rem = 10px — базис для миксинов в src/lib/styles/_text.scss */
}

body {
  font-size: 1.4rem; /* 14px по умолчанию */
  line-height: 1.5;
}
```

После этого все компоненты, использующие миксины `text`, `text-s`, `text-b`, `h1`, `h2`, `h3` и т.п., автоматически получат корректные размеры:
- `text` (1.4rem) → 14px вместо 22.4px
- `text-s` (1.4rem) → 14px вместо 22.4px
- `text-b` (1.6rem) → 16px вместо 25.6px
- `h1` (2.4rem) → 24px вместо 38.4px
- `h2` (2rem) → 20px вместо 32px
- `h3` (1.6rem) → 16px вместо 25.6px

### 2. DialogSelect — без изменений

Все размеры в `DialogSelect.module.scss` заданы в `px` напрямую и не зависят от `html font-size`. Останутся такими же, как сейчас (14–20px).

### 3. Демо-страница — без изменений

В `src/routes/index.tsx` Tailwind-утилиты (`text-sm`, `text-lg`, `text-4xl` и т.д.) используют свои собственные `rem` значения, которые также пересчитаются (`text-sm` будет 8.75px вместо 14px). Поэтому добавлю изменение в `src/styles.css` (root приложения), а не в `src/lib/styles.css`:

**Уточнение размещения:** правило `html { font-size: 62.5% }` нужно добавить так, чтобы оно применялось при использовании библиотеки И на демо-странице. Но если демо тоже его «съест», Tailwind на демо-странице станет мельче.

**Финальный вариант — изоляция через scope:**

Применим reset только к корню, где живут компоненты библиотеки. Поскольку компоненты библиотеки могут жить где угодно, проще использовать `:root` и одновременно компенсировать Tailwind на демо-странице, увеличив корневой текст обёртки `<main>` через `style={{ fontSize: '16px' }}` или класс. Но это хрупко.

**Чистое решение:** добавить `html { font-size: 62.5% }` в `src/styles.css` (приложения) и поправить размеры заголовков/подписей на демо-странице вручную (они и так с явными Tailwind-классами — Tailwind пересчитается, но визуально страница уже была плотной, разница небольшая; при необходимости донастрою).

**Итого правки:**

1. `src/styles.css` — добавить:
   ```css
   html { font-size: 62.5%; }
   body { font-size: 1.4rem; }
   ```
   (вне `@layer base`, сразу после `:root` блока).

2. После применения проверить демо-страницу `/` через preview:
   - Все компоненты библиотеки — шрифт стал ~14px (было ~22px).
   - DialogSelect — без изменений (px).
   - Tailwind-обёртки демо (заголовки секций, шапка) — стали мельче пропорционально. Если выглядит плохо, точечно поправлю классы (`text-4xl` → `text-5xl` и т.п.) уже после визуальной проверки.

## QA

После изменений открою `/` в превью, сравню визуально размер текста в Button, Select, Tabs, Tag, Popover, Tooltip, Card, BaseBlock, Collapse, RadioGroupButton — должен стать заметно мельче. DialogSelect должен выглядеть так же.
